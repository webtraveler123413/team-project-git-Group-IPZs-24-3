Завдання 1  



Визначення архітектурного підходу. 



Для даного проекту буде використовуватися мікросервісна архітектура, тому що дана архітектура легко масштабується, та для її реалізації можна використовувати різні технології для різних сервісів. 



Завдання 2 



У даному проекті є такі модулі: 



&nbsp;   Мобільний додаток: 



Сулугує для комунікації між користувачем та додатком. 



Ролі користувачів: гість та користувач. 



&nbsp;   Модуль для входу: 



Дозволяє увійти у додаток. 



Ролі користувачів: користувач. 



&nbsp;   Модуль для покупки квитків: 



Дозволяє вибрати рейс та місце для сидіння та отримати цифровий квиток. 



Ролі користувачів: користувач. 



&nbsp;   Модуль для оплати: 



Дозволяє вибрати сервіс для оплати та оплатити ціну квитка. 



Ролі користувачів: користувач. 



&nbsp;   Модуль адміністрування: 



Дозволяє вносити зміни у додаток та редагувати та видаляти обілкові записи користувачів. 



Ролі користувачів: адміністратор. 



&nbsp;   Модуль для реєстрації: 



Дозволяє зареєструвати обліковий запис у додаток. 



Ролі користувачів: гість. 



&nbsp;   Сервер: 



Дозволяє зберігати та обробляти дані від користувачів. 



Ролі користувачів: адміністратор.
